## Rules

-   Only list files currently being changed for the active task.
-   Remove files when the task is finished.
-   If work pauses, leave the files listed and explain why.
-   Never claim a task is complete merely because files exist.
-   Keep generated build artifacts out unless they are intentionally
    part of the repository.
