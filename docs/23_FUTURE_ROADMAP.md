# Future Roadmap

## V1.1

-   better record quality UI;
-   Excel export;
-   improved retry dashboard;
-   saved filters;
-   richer audit viewer.

## V1.2

-   additional permitted provider adapters;
-   webhook delivery;
-   API keys for downstream applications;
-   advanced schedules.

## V2

-   multi-user teams;
-   role-based access;
-   project sharing;
-   usage dashboards;
-   managed deployment;
-   optional Docker support.

## V3

-   provider marketplace/plugin system;
-   advanced analytics;
-   change detection;
-   configurable data pipelines;
-   enterprise observability.

## Explicitly excluded

The roadmap must not add features whose primary purpose is bypassing
third-party access controls, defeating CAPTCHA systems, evading rate
limits, or collecting private/restricted data.
