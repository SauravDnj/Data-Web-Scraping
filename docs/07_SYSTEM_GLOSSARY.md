# System Glossary

**Project:** user-owned collection workspace.

**Collection configuration:** versioned definition of what the provider
operation should request.

**Job:** durable request to execute one configuration version.

**Job run:** one worker execution attempt for a job.

**Work unit:** provider/application-defined unit of processing.

**Record:** normalized application data item.

**Provenance:** information explaining how/when a record was obtained.

**Provider adapter:** isolated integration with an external data
provider.

**Canonical key:** deterministic identity used for deduplication.

**Queue:** temporary transport for work.

**System of record:** durable MySQL application state.

**Schedule:** rule that creates future jobs.
